# Edona Çadraku — Portfolio

A responsive personal portfolio built with React and Create React App. The visual direction is an original, minimal editorial design, with project information and screenshots retained from this portfolio.

## Run locally

1. Open this folder in Visual Studio Code.
2. In the integrated terminal, run `npm install` if dependencies have not been installed yet.
3. Run `npm start`.
4. Open [http://localhost:3000](http://localhost:3000).

The source is in `src/`. Project screenshots are imported from `src/`; the portrait, CV, and favicon are in `public/`.

## Update portfolio content

- Edit the introduction and profile copy in `src/components/About.js`.
- Edit project text, links, and screenshot lists in `src/components/Projects.js`.
- Replace project images in `src/` and update their imports in `Projects.js`.
- Update contact details in `src/components/Contact.js`.
- Global colors, typography, responsive layout, and motion preferences are in `src/App.css`.

The contact links open email, phone, and professional profiles directly. There is no contact form or backend integration.
